## 🧬 About

**NET-ACADEMY** is an interactive, standalone networking education platform designed to build a strong foundation in computer networking and cybersecurity.

Instead of presenting networking as a collection of boring notes, the project combines structured lessons, visual UI, interactive elements, quizzes, progress tracking, a command cheat sheet, and a learning roadmap.

The course currently presents **20 educational sections, 7 OSI layers, 40+ key protocols, and a 12-step roadmap**.

> **Learn the network. Understand the system. Build the security mindset.**

# 🧠 Topics

### 01 — Networking Fundamentals

Build the foundation required to understand modern computer networks.

### 02 — OSI + TCP/IP

Learn the relationship between the OSI and TCP/IP models and understand what happens at each layer.

### 03 — IP & Subnetting

```text
IPv4
IPv6
CIDR
Subnet Masks
Network Address
Broadcast Address
Host Ranges
Subnet Calculations
```

### 04 — MAC & ARP

Understand Layer 2 addressing, MAC addresses and ARP communication.

### 05 — Switching

Learn how switches make forwarding decisions and maintain MAC/CAM information.

### 06 — VLAN

Understand network segmentation and VLAN-based architectures.

### 07 — Routing

Explore:

```text
Static Routing
OSPF
BGP
Routing Tables
Default Routes
```

### 08–11 — Network Services

Core network services including:

```text
DNS
DHCP
NAT
```

### 12+ — Wireless & Physical Networking

Explore wireless networking, cables and fiber-optic concepts.

### Network Security

Understand foundational network security concepts including:

```text
Firewall
IDS
ACL
Segmentation
ARP Security
Network Attacks
Defensive Controls
```

### Troubleshooting

Learn the purpose of common diagnostic tools:

```bash
ping
traceroute
netstat
tcpdump
ip
arp
```

The project's cheat sheet also includes examples involving `nmap`, `tcpdump`, `arp-scan`, `nmcli`, `ipcalc`, DHCP, and NAT configuration.

# 🚀 Installation

NET-ACADEMY does **not require a backend, database, package manager, or framework**.

### 1. Clone

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Enter the project

```bash
cd YOUR-REPOSITORY
```

### 3. Open

Simply open:

```text
network.html
```

in your browser.

### Or run a local server

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/network.html
```

# ⚡ Cheat Sheet

The built-in cheat sheet provides practical command examples for networking tasks.

```bash
# Network interfaces
ip addr

# Routing table
ip route

# Connectivity
ping 8.8.8.8

# Trace route
traceroute 8.8.8.8

# Service discovery
nmap -sV 192.168.1.1

# Packet capture
sudo tcpdump -i eth0 -nn port 80

# MAC information
ip link show

# ARP discovery
sudo arp-scan --local

# Wi-Fi networks
nmcli dev wifi list

# Subnet calculation
ipcalc 192.168.1.0/27
```

> ⚠️ Use network-scanning and packet-analysis tools only on systems and networks you own or are explicitly authorized to test.
