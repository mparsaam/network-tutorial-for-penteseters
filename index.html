مقدمه — شبکه‌های کامپیوتری چرا مهم‌اند؟

سطح: مبتدی

بدون شبکه، ابزارهای هکری هیچ‌کدوم کار نمی‌کنن. هیدرا به شبکه وصل می‌شه، متاسپلویت پکت می‌فرسته، WPScan HTTP درخواست می‌ده — همه به زیرساخت شبکه وابسته‌ان. اگه نتورک رو بلد نباشی، مثل برق‌کاری می‌مونی که نمی‌دونه برق چیه!

***شبکه*** = مجموعه‌ای از دستگاه‌های متصل (کامپیوتر، سرور، روتر، سوئیچ) که می‌تونن داده رو با هم به اشتراک بذارن — از دو تا کامپیوتر تو یه خونه تا اینترنت جهانی.

چرا برای هکرها حیاتی‌ست؟

  • 🔍 شناسایی: تشخیص سرویس‌ها و پورت‌های باز (Nmap, netstat)
  • ⚔️ حملات: ARP Spoofing, MITM, DNS Poisoning, DDoS
  • 🔄 مسیریابی: Pivoting و عبور از شبکه‌های داخلی
  • 🛡️ دفاع: فایروال، ACL, NAC, Segmentation
✅ شبکه پایه‌ی تمام تست‌های نفوذه — این دوره رو جدی بگیر.

مدل OSI و TCP/IP — الفبای شبکه

بنیادی

دو مدل اصلی برای توضیح چگونگی کار شبکه وجود داره: OSI (Open Systems Interconnection) ۷ لایه و TCP/IP ۴ لایه. به‌عنوان یه هکر، OSI رو برای تفکر و TCP/IP رو برای عمل باید بلد باشی.

آدرس IP و Subnetting — حیاتی‌ترین مبحث

مهم

***IPv4*** = Internet Protocol version 4: آدرس ۳۲ بیتی که به صورت ۴ بخش ۸ بیتی (مثل 192.168.1.1) نوشته می‌شه. حدود ۴/۳ میلیارد آدرس. و ***IPv6*** = نسخه ۶ با ۱۲۸ بیت آدرس، مثلاً 2001:db8::1 — برای حل مشکل کمبود آدرس

کلاس‌های IP

کلاسمحدودهپیش‌فرض Subnet Maskکاربرد
A1.0.0.0 — 127.255.255.255255.0.0.0 (/8)شبکه‌های بزرگ (ISP)
B128.0.0.0 — 191.255.255.255255.255.0.0 (/16)شرکت‌های متوسط
C192.0.0.0 — 223.255.255.255255.255.255.0 (/24)شبکه‌های کوچک (شرکت‌ها)
D224.0.0.0 — 239.255.255.255-Multicast
E240.0.0.0 — 255.255.255.255-مختص آزمایش

آدرس‌های خصوصی (Private IP)

  • 10.0.0.0/8: 10.0.0.0 تا 10.255.255.255 (شبکه‌های بزرگ)
  • 172.16.0.0/12: 172.16.0.0 تا 172.31.255.255 (متوسط)
  • 192.168.0.0/16: 192.168.0.0 تا 192.168.255.255 (خانگی/کوچک)
  • 127.0.0.0/8: Loopback (localhost)

💡 فرمول طلایی: تعداد Host = 2^(32-CIDR) - 2. مثلاً /24 = 2^(8)-2 = 254 host. منهای دو تا برای Network ID و Broadcast.

مثال عملی ساب‌نتینگ

فرض کن 192.168.1.0/24 داری و باید ۴ شبکه جدا با ۳۰ تا host بسازی:

  • شبکه ۱: 192.168.1.0/27 (۱-۳۰) — 192.168.1.0 Network, 192.168.1.31 Broadcast
  • شبکه ۲: 192.168.1.32/27 (۳۳-۶۲)
  • شبکه ۳: 192.168.1.64/27 (۶۵-۹۴)
  • شبکه ۴: 192.168.1.96/27 (۹۷-۱۲۶)
🧪 کوییز کوتاه
۱) در یک شبکه /28 چند host قابل استفاده داریم؟
جواب: ۱۴. 2^(32-28)=16. منهای Network ID و Broadcast = 14.
۲) آدرس 192.168.1.255 در شبکه /24 چیست؟
جواب: Broadcast. آخرین آدرس هر subnet آدرس Broadcast است.

MAC Address و ARP Protocol

لایه ۲

***MAC Address*** = Media Access Control: آدرس فیزیکی ۶ بایتی منحصربه‌فرد که روی کارت شبکه هر دستگاه ذخیره شده (مثل 00:1A:2B:3C:4D:5E). برخلاف IP که منطقی و قابل تغییره، MAC فیزیکی و (باید) یکتاست.

***ARP*** = Address Resolution Protocol: پروتکلی که آدرس IP رو به MAC تبدیل می‌کنه — "کی IP 192.168.1.1 رو داره؟ میشه MAC‌ت رو بهم بگی؟"

arp -a   # ویندوز/لینوکس
# مثال:
# 192.168.1.1    00-1A-2B-3C-4D-5E     dynamic
ip link show   # لینوکس
ipconfig /all  # ویندوز (جستجوی Physical Address)
⚠️ حملات ARP: ARP Spoofing یا ARP Poisoning یکی از خطرناک‌ترین حملات لایه ۲ — هکر می‌تونه خودش رو جای Gateway جا بزنه و همه ترافیک رو بشنوه (MITM). جلوی این حمله با Dynamic ARP Inspection (DAI) و IP Source Guard گرفته می‌شه.
arp-scan --local   # لینوکس
# دستگاه‌های موجود در شبکه محلی را نشان می‌دهد
💡 اگه هکر باشی، ARP Spoofing اولین تکنیکی‌ه که برای حمله در شبکه‌های محلی امتحان می‌کنی — با ابزارهایی مثل Bettercap, Ettercap, arpspoof.

سوئیچینگ — چطور دستگاه‌ها همدیگه رو پیدا می‌کنن؟

لایه ۲

***سوئیچ (Switch)*** = دستگاهی در لایه ۲ که با استفاده از MAC Address جدول (CAM Table) پکت‌ها رو به پورت مقصد هدایت می‌کنه. برخلاف Hub که به همه پورت‌ها می‌فرسته، سوئیچ فقط به پورت مقصد می‌فرسته.

مفاهیم کلیدی سوئیچینگ

  • MAC Table (CAM Table): جدولی که MACها رو به پورت‌ها وصل می‌کنه
  • Flooding: وقتی MAC مقصد تو جدول نیست، به همه پورت‌ها می‌فرسته (جز پورت مبدأ)
  • Learning: سوئیچ MAC مبدأ رو یاد می‌گیره و به جدول اضافه می‌کنه
  • Forwarding/Filtering: تصمیم‌گیری ارسال یا مسدود کردن
  • Broadcast Domain: همه دستگاه‌هایی که broadcast رو دریافت می‌کنن

حملات به سوئیچ

حملهروشدفاع
MAC Floodingپر کردن CAM Table با MACهای جعلیPort Security
STP Manipulationتغییر Spanning Tree برای MITMBPDU Guard, Root Guard
VLAN Hoppingپریدن از یک VLAN به VLAN دیگرDisable DTP, Native VLAN تغییر
ARP Spoofingجعل ARP برای MITMDAI, IP Source Guard
show mac address-table
# یا: show mac address-table dynamic
💡 برای یه تست‌کننده نفوذ، فهمیدن این که چطور سوئیچ کار می‌کنه یعنی می‌دونی چطور ازش بزنی بیرون یا چطور detection رو دور بزنی.

VLAN — شبکه‌های مجازی مجزا

جداسازی

***VLAN*** = Virtual Local Area Network: تقسیم یک شبکه فیزیکی به چند شبکه منطقی مجزا — دستگاه‌های توی VLANهای مختلف بدون روتر نمی‌تونن با هم حرف بزنن. مثل اینه که چند تا سوئیچ مجازی توی یه سوئیچ فیزیکی داشته باشی.

VLANنامکاربرد
۱Default (Native)پیش‌فرض — توصیه نمی‌شه تغییرش بدی
۱۰Managementمدیریت سوئیچ/روتر
۲۰Usersکاربران عادی
۳۰Serversسرورها (ایمن‌تر)
۹۹VoiceVoIP
۴۰۹۵ExtendedVLANهای بالا (۴۰۹۶ عدد)

Trunk — اتصال بین سوئیچ‌ها

وقتی می‌خوای چند VLAN رو بین دو سوئیچ منتقل کنی، از Trunk Port استفاده می‌کنی. پروتکل ***802.1Q*** = استاندارد Tagging VLAN — یه تگ ۴ بایتی به فریم اضافه می‌کنه تا مشخص کنه این فریم مال کدوم VLAN هست روی لینک Trunk استفاده می‌شه.

enable
configure terminal
vlan 20
 name USERS
exit
interface fastEthernet 0/1
 switchport mode access
 switchport access vlan 20
⚠️ VLAN Hopping: مهاجم می‌تونه با سوئیچ‌گرام جعلی (DTP) به VLANهای دیگه نفوذ کنه. همیشه DTP رو روی سوئیچ غیرفعال کن: switchport mode access + switchport nonegotiate

راوترینگ (Routing) — چطور داده به مقصد می‌رسه؟

لایه ۳

***Routing*** = فرآیند انتخاب بهترین مسیر برای رسیدن بسته از مبدأ به مقصد در یک شبکه وسیع (WAN/Internet). روترها با استفاده از Routing Table تصمیم می‌گیرن بسته رو به کجا بفرستن.

انواع مسیریابی

  • Static Routing: مسیر رو دستی توی روتر می‌نویسی — برای شبکه‌های کوچک
  • Dynamic Routing: روترها خودشون مسیر رو یاد می‌گیرن با پروتکل‌هایی مثل OSPF, EIGRP, BGP
  • Default Route: 0.0.0.0/0 — "بقیه رو بفرست به اینجا" (Gateway)
ip route show
route -n
show ip route

حیاتی

***DNS*** = Domain Name System: سیستمی که نام دامنه (مثل google.com) رو به IP (مثل 142.250.185.46) تبدیل می‌کنه — کتاب تلفن اینترنت

DHCP — تخصیص خودکار آدرس IP

لایه ۲/۳

***DHCP*** = Dynamic Host Configuration Protocol: پروتکلی که خودکار به دستگاه‌های متصل به شبکه، IP، subnet mask، gateway و DNS می‌ده. چهار مرحله اصلی: DORA — Discover, Offer, Request, Acknowledge.

مراحل DORA

  1. Discover: کلاینت می‌گه "یکی منو پیدا کنه!" (Broadcast)
  2. Offer: سرور DHCP می‌گه "بیا این IP رو بگیر"
  3. Request: کلاینت می‌گه "همین IP رو می‌خوام"
  4. Acknowledge: سرور می‌گه "مال تو!"
dhclient -v eth0   # لینوکس — درخواست IP جدید
ip addr show eth0  # نمایش IP فعلی
# با Yersinia یا Bettercap می‌تونی DHCP جعلی راه بندازی:
bettercap -eval "set dhcpd.enable true; set dhcpd.range 192.168.1.100-192.168.1.200; dhcpd on"
# این رو در شبکه‌های آزمایشی خودت انجام بده
⚠️ Rogue DHCP Server: هکر با راه‌اندازی یک DHCP جعلی می‌تونه به دستگاه‌ها Gateway جعلی بده و همه ترافیک رو بشنوه. دفاع: DHCP Snooping در سوئیچ‌ها.
🔄

NAT — ترجمه آدرس شبکه

لایه ۳

***NAT*** = Network Address Translation: تکنیکی که IP خصوصی (داخلی) رو به IP عمومی (خارجی) تبدیل می‌کنه تا چندتا دستگاه بتونن با یه IP عمومی به اینترنت وصل بشن. مودم خونه‌ت رو نگاه کن — NAT داره.

انواع NAT

  • SNAT (Source NAT): تغییر IP مبدأ — معمولاً توسط روتر خونه انجام می‌شه (Masquerade)
  • DNAT (Destination NAT): تغییر IP مقصد — پورت فورواردینگ (Port Forwarding)
  • PAT (Port Address Translation): چندتا دستگاه از یه IP عمومی با پورت‌های مختلف استفاده می‌کنن
  • Static NAT: یک به یک بین IP خصوصی و عمومی
# SNAT (Masquerade):
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

# DNAT (Port Forward):
iptables -t nat -A PREROUTING -p tcp --dport 80 -i eth0 -j DNAT --to-destination 192.168.1.100:80
💡 برای تست‌کننده نفوذ، NAT به معنی پایان شبکه داخلیست — اگه پشت NAT باشی نمی‌تونی مستقیم پیلود Reverse بگیری مگر اینکه از UPnP یا Port Forwarding استفاده کنی.
📶

شبکه‌های وایرلس (Wi-Fi)

لایه ۱/۲

***Wi-Fi*** = Wireless Fidelity: خانواده‌ای از استانداردهای IEEE 802.11 برای شبکه‌های بیسیم محلی. فرکانس‌های ۲.۴GHz و ۵GHz و جدیداً ۶GHz (Wi-Fi 6E).

  • WEP: شکسته شده — فقط چند دقیقه طول می‌کشه تا کرک بشه (هیچوقت استفاده نکن)

امنیت شبکه — مفاهیم پایه

حفاظت

شبکه‌ها بدون امنیت مثل خونه‌ای هستن که درش بازه — این ابزارهای دفاعی رو یاد بگیر:

Firewall — فایروال

فایروال ترافیک رو بر اساس قوانین (Rules) مسدود یا مجاز می‌کنه. انواع:

  • Packet Filtering (Stateless): چک کردن IP و پورت مبدأ/مقصد — ساده ولی ضعیف
  • Stateful Firewall: وضعیت اتصال رو نگه می‌داره (باهوش‌تر)
  • Next-Gen (NGFW): تشخیص برنامه (Application ID) و کاربر (User ID)
  • Web Application Firewall (WAF): محافظ وب — مثل Cloudflare, Wordfence

IDS / IPS

  • IDS (Intrusion Detection System): تشخیص نفوذ — هشدار می‌ده
  • IPS (Intrusion Prevention System): جلوگیری از نفوذ — بلوک می‌کنه

VPN — شبکه خصوصی مجازی

رمزگذاری تمام ترافیک بین دو نقطه. انواع: IPsec, OpenVPN, WireGuard. در تست نفوذ برای مخفی کردن IP (زنجیره‌ای) استفاده می‌شه.

ACL (Access Control List)

لیست مجوزها روی روتر/سوئیچ/فایروال — "کی به کجا می‌تونه دسترسی داشته باشه". انواع استاندارد (IP مبدأ) و توسعه‌یافته (IP+Port مبدأ/مقصد).

access-list 100 permit tcp 192.168.1.0 0.0.0.255 host 10.0.0.1 eq 443
access-list 100 deny ip any any
interface gigabitEthernet 0/0
ip access-group 100 in
💡 برای یه تست‌کننده نفوذ، درک ACL یعنی می‌دونی چطور مسیرهای عبور رو پیدا کنی و از کجا رد بشی.

عیب‌یابی شبکه — ابزارهای ضروری

مهارت نجات

وقتی شبکه باگ داره — این دستورات رو به ترتیب بزن:

۱) ping — آیا دستگاه جواب می‌ده؟

ping 192.168.1.1
ping -c 4 google.com

۲) ipconfig / ip addr — آدرس IP من چیه؟

ip addr show       # لینوکس
ipconfig           # ویندوز

۳) traceroute / tracert — مسیر کجاست؟

traceroute google.com   # لینوکس
tracert google.com      # ویندوز

۴) netstat / ss — چه پورت‌هایی بازه؟

netstat -tulpn   # لینوکس — همه پورت‌های listening
ss -tulpn        # جدیدتر و سریع‌تر
netstat -ano     # ویندوز

۵) nmap — اسکنر شبکه

nmap -sn 192.168.1.0/24   # Ping Sweep — کشف دستگاه‌ها
nmap -sV 192.168.1.1      # شناسایی سرویس

۶) tcpdump / Wireshark — شنود ترافیک

sudo tcpdump -i eth0 -n
sudo tcpdump -i eth0 port 80 -X   # ترافیک HTTP رو نشون بده
